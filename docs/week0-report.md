# PBL Report - Week 0 (Idea and Prototype)

**Project:** AI-Powered Adaptive SSH Honeypot

## Problem statement
Attackers scan the internet for servers to break into. Traditional honeypots (decoy servers) give
fixed, scripted replies, so experienced attackers recognise and avoid them. This project builds a
honeypot whose responses are generated by an LLM, making the decoy adapt to any command and stay
believable, while logging every action and mapping it to MITRE ATT&CK techniques.

## Objectives
1. Fake SSH service that accepts any credentials and logs them
2. LLM-generated, session-consistent terminal responses
3. Automatic mapping of commands to MITRE ATT&CK
4. Analysis dashboard and attacker profiling

## Work completed (prototype)
- SSH server (asyncssh) with credential capture and full session logging (JSONL)
- LLM response engine with offline fallback
- ATT&CK rule mapper (16 technique rules)
- Log analysis script (top IPs, commands, techniques, credentials)
